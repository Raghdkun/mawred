# ADR-0011: i18n with react-i18next; RTL by logical properties

- Status: Proposed
- Date: 2026-10-13

## Context
The brief asks for react-i18next or laravel-react-i18n, with a justification. As of 2026-10, `laravel-react-i18n` (2.0.5) has had no release or commit since 2024-10. `i18next` 26 / `react-i18next` 17 are actively maintained, support ICU and `Intl.PluralRules` (Arabic has six plural categories: zero, one, two, few, many, other), lazy namespaces and Suspense.

## Decision
- Locales: **EN (default) + AR** (D3), chosen per user. The browser `Accept-Language` is used only before login.
- **react-i18next** + `i18next-icu` for the UI.
- Single source: `lang/{en,ar}/*.php` holds server strings (validation, mail, PDF, notifications), and `lang/{en,ar}/ui/<namespace>.json` holds UI strings. A Vite plugin (in-repo, ~50 lines) exposes the JSON namespaces as lazily imported chunks. CI checks key parity between `en` and `ar` (missing keys fail the build). `ar` is the reference for plural forms.
- Locale switch: `PATCH /me/locale`, then the client loads the namespaces, `i18n.changeLanguage`, sets `<html lang dir>`, and Inertia does a partial reload of `auth`/`locale` props. No full page reload.
- Dates and numbers: `Intl.*` + date-fns locales `ar`/`en-US`; digits follow `data-digits` (`latn` default, `arab` optional per user); Hijri via the `islamic-umalqura` calendar.
- **RTL**:
  - Logical utilities only, enforced by `eslint-plugin-better-tailwindcss` `enforce-logical-properties` under ESLint 10 (D17; the kit's vite-plus/oxlint is removed), configured to flag **inline (left/right) axis only** so top/bottom classes are left alone.
  - Icons that imply direction (chevrons, arrows, "back", progress) get `rtl:-scale-x-100` through the `<DirIcon>` wrapper.
  - Motion slide offsets come from `useDir()`.
  - Bidirectional text isolation (`<bdi>`, `unicode-bidi: isolate`) for names, numbers and refs inside opposite-direction text.
- Tests: Pest browser journeys run in both `en` and `ar`; Vitest renders key components in both `dir`s.
